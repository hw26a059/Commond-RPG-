# 6. 味方キャラクター設定・初期ステータス

本作でプレイヤーが操作可能な3人のキャラクターの初期パラメータおよび役割の定義です。

## 6.1 キャラクター特性一覧

| キャラクター詳細 | キャラクターA（火） | キャラクターB（水） | キャラクターC（風） |
| :--- | :---: | :---: | :---: |
| **主な役割** | 物理アタッカー / 壁役 | バランス / バフ・デバフ | 魔法アタッカー / 回復役 |
| **初期最大 HP** | **200** | **120** | **100** |
| **初期最大 MP** | **50** | **160** | **200** |
| **初期最大 SP** | **100** | **110** | **100** |

## 6.2 各キャラクターの戦闘設計

### キャラクターA （属性：**火** / 固有能力：**追撃**）
- **プレイスタイル**: HPと物理防御力、物理攻撃力が非常に高いフロントライナー。MPは低め。
- **シナジー**: 物理技を重ねて大ダメージを出し、固有能力「追撃（消費SP 40）」によって、そのターンの総ダメージの80%分を追撃ダメージとして叩き出す単体瞬間火力に長けています。

### キャラクターB （属性：**水** / 固有能力：**トレース**）
- **プレイスタイル**: 魔力と魔法防御、MPに優れた万能型キャラクター。
- **シナジー**: 攻撃と補助、回復などを幅広くこなし、固有能力「トレース（消費SP 60）」で「直前に自身が放った行動を再度そのまま発動」することで、回復魔法２連打や、バフ２連打など柔軟な盤面コントロールを可能とします。

### キャラクターC （属性：**風** / 固有能力：**集中**）
- **プレイスタイル**: 最も高い魔力とMPを持つが、HPや防御力が低めなガラスの砲台/ヒーラー。素早さはやや遅め。
- **シナジー**: 威力の高い風属性魔法や強力な全体回復を扱い、固有能力「集中（消費SP 90）」を使うことで、そのターンの行動がすべて確定「超会心」（通常の会心の2倍、つまり大ダメージ）に変化。ここ一番のバーストダメージや、形勢を立て直す超回復を狙いに行きます。
