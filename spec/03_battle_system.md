# 3. バトルシステム（属性・状態異常）

属性相性によるダメージ補正や、各種状態異常の付与を伴う戦闘システムを構築します。

## 3.1 属性相性システム
本作の属性システムは、以下の関係性を持つ「三すくみ」の属性相性を採用します。

### 属性の相性関係
- **火 属性**：風属性に有利、水属性に不利
- **水 属性**：火属性に有利、風属性に不利
- **風 属性**：水属性に有利、火属性に不利

```
   ┌─── 火 ───┐
   ▼          │
  風 ◄─────── 水
```

### 属性ダメージ補正値
- **有利属性への攻撃**: ダメージ **160% (1.6倍)**
- **不利属性への攻撃**: ダメージ **60% (0.6倍)**
- 同属性・無属性同士の攻撃は補正なし（100%、1.0倍）

### 攻撃の種類
各キャラクターは以下の2つの異なる攻撃タイプを使い分けることができます：
- **物理攻撃**：属性相性の影響を受けず、相手の物理防御力に依存する標準的な攻撃。
- **属性攻撃**：上記の「火・水・風」属性を持ち、相性によるダメージ補正や状態異常付与を伴う攻撃。

### キャラクター・敵モンスターの属性特性
- プレイヤーキャラクター、および敵モンスター自体にもそれぞれ**固有の属性（火・水・風のいずれか、もしくは無属性など）**が設定されています。
- そのため、敵の属性に対する相性を考慮して攻撃方法（物理・対応属性）を適切に選択する戦術が求められます。

## 3.2 状態異常システム
戦闘中の攻撃（特に属性攻撃）やスキル、あるいはイベントによって付与される状態異常を定義します。
状態異常の基本的な**継続ターン数はすべて「3ターン」**を想定します。

| 状態異常名 | 効果内容 | 継続ターン |
| :--- | :--- | :--- |
| **スタン** | 行動不能になる（そのターンの発動コマンドがスキップされます）。 | 3ターン |
| **火傷** | ターン終了毎に、一定の割合ダメージ（スリップダメージ）を受ける。 | 3ターン |
| **風化** | 肉体が風化し脆弱化することで、**受けるすべてのダメージが増加する**ペナルティ状態。 | 3ターン |
| **攻撃力低下** | 一時的に外部に出力できる攻撃性能が減退し、与ダメージが減少する。 | 3ターン |
| **防御力低下** | 防御能力が減退し、被ダメージが増加する。 | 3ターン |
