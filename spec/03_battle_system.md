# 3. バトルシステム（属性・状態異常）

属性相性によるダメージ補正や、各種状態異常の付与を伴う戦闘システムを構築します。

## 3.1 属性相性システム
本作の属性システムは、以下の関係性を持つ「三すくみ」の属性相性を採用します。

### 属性の相性関係
- **火 属性**：風属性に有利、水属性に不利
- **水 属性**：火属性に有利、風属性に不利
- **風 属性**：水属性に有利、火属性に不利

```
   ┌─── 火 ───┐
   ▼          │
  風 ◄─────── 水
```

### 属性ダメージ補正値
- **有利属性への攻撃**: ダメージ **160% (1.6倍)**
- **不利属性への攻撃**: ダメージ **60% (0.6倍)**
- 同属性・無属性同士の攻撃は補正なし（100%、1.0倍）

### 攻撃の種類
各キャラクターは以下の2つの異なる攻撃タイプを使い分けることができます：
- **物理攻撃**：属性相性の影響を受けず、相手の物理防御力に依存する標準的な攻撃。
- **属性攻撃**：上記の「火・水・風」属性を持ち、相性によるダメージ補正や状態異常付与を伴う攻撃。

### キャラクター・敵モンスターの属性特性
- **キャラクターの属性**: プレイヤーキャラクターはそれぞれ**1人1種類のみ**、固有の特定の属性（火・水・風のいずれか）を宿しています。単一のキャラクターが複数の属性攻撃を扱うことはありません。
- **攻撃手段の割り当て**: 各キャラクターは、属性影響のない共通の「物理攻撃」と、自身が宿す属性に完全に特化した「対応属性の攻撃/技」を所持しています。
- **敵の属性特性と相性活用制約**: 敵モンスターにも個別の弱点属性・得意属性（火・水・風の三すくみ）が確実に設定されています。この相性を意識し、有利なキャラクターで属性攻撃を叩き込み、不利な状況では物理攻撃や補助・回復に回すなどの「三すくみ戦略」をフルに活用する必要があります。

## 3.2 状態異常システム
戦闘中の攻撃（特に対応した属性攻撃や一部技）やスキル、あるいは突発イベントによって付与される状態異常を定義します。
状態異常の基本的な**継続ターン数はすべて「3ターン」**です。

| 状態異常名 | 効果詳細 | 継続ターン |
| :--- | :--- | :--- |
| **スタン** | 脳震盪などによる肉体活動の停止。そのキャラクターは行動不能になる（そのターンに選択したコマンドがすべてスキップされます）。 | 3ターン |
| **火傷** | 身体が燃え続けるペナルティ状態。毎ターン終了時に、現在HPに対する一定割合のダメージ（スリップダメージ）を受ける。 | 3ターン |
| **風化** | 肉体が風化し崩れやすく（脆く）なる状態。付与されている間、**受けるすべてのダメージが増加（被ダメージ上昇）**する。 | 3ターン |
| **攻撃力低下** | 一時的な虚脱、または呪い。与える物理・属性ダメージが減少（デバフ効果）する。 | 3ターン |
| **防御力低下** | 装甲の劣化、または威圧。受ける被ダメージが増加（デバフ効果）する。 | 3ターン |
