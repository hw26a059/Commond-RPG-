# 2. キャラクター・スキル仕様

本作では、キャラクターが持つ固有能力と、通常技を組み合わせることで、1ターンに強力な連続・強化行動を行うシステムを採用します。

## 2.1 技の組み合わせ構成
1人のキャラクターが1つのターンで、以下の3つの要素を同時に選択して発動します。
- **「技A」 ＋ 「技B」 ＋ 「固有能力（スキル）」 ＝ 1アクションとしての発動**

### 発動ルールとリソース消費
- **技の実行**: 通常の技の使用には、対応するリソース（MP等）を想定。
  - **同じ技を2つ選択（例：ファイア ＋ ファイア ＋ 固有能力）することも可能**です。
  - 攻撃技だけでなく、**回復技や補助技を任意に組み合わせることも可能**です。（例：回復技 ＋ 物理攻撃 ＋ トレース）
- **固有能力の発動**: 固有能力（スキル）の使用には**SP（スキルポイント）**を消費します。

### SPの回復ルール
- **行動ごとにSPが一定量回復**する仕組みを採用します（例：技を発動するなどの自身の行動順が完了した際、一定値SPが蓄積・回復する）。

---

## 2.2 登場キャラクターと固有能力
プレイヤーが操作可能なキャラクターは**3名**で、それぞれの固有能力（スキル）は**1名に1つずつ完全に固定**されて割り当てられています。

| キャラクター | 固定の固有能力 | 効果詳細 | 消費リソース |
| :--- | :--- | :--- | :--- |
| **キャラクターA** | **追撃** | 自身の攻撃（技A・技Bなど）を行った後、与えた総ダメージの80%分の追加ダメージを対象に与える。 | SP消費あり |
| **キャラクターB** | **トレース** | 自身の攻撃、もしくはスキル（技）発動後に、全く同じ行動をもう一度繰り返す。 | SP消費あり |
| **キャラクターC** | **集中** | そのターンに自身が与えるダメージが必ず「超会心」となる（超会心は、通常の会心ダメージの2倍の威力を発揮する）。 | SP消費あり |
