# 1. ゲーム概要

本作は、キャラクターごとの固有能力（スキル）と、通常技を組み合わせることで強力なシナジー（倍率補正、複数回行動、超会心）を発動できる「1ターン内複数コマンド同時選択式」の戦略的コマンドRPGです。
また、属性相性、状態異常、および3ターンごとの突発イベントなど、戦況が目まぐるしく変化するギミックを搭載しています。

## 1.1 基本コンセプト
- **キャラクター固有システム**: それぞれ異なる独自の「固有能力」を持つ3人のキャラクター。
- **技とスキルの融合**: 1人のキャラクターが1ターン内に「技A ＋ 技B ＋ 固有能力（SP消費）」を同時選択して発動する。
- **動的なバトル展開**: 火・水・風による三すくみ相性、戦況を左右する各種状態異常、および3ターンごとの固定で発生し、次のイベントまで3ターン継続する突発イベント。
- **洗練されたUI**: PCに最適化した1画面レイアウト、およびスクロールを要さず直近の3〜5行のみを表示する、行動ごとの結果を1行に集約した流動的な戦闘ログ。

## 1.2 ゲームの基本フロー（想定）
1. プレイヤーと敵の対峙（バトル開始）
2. ターン開始時：コマンド選択（各キャラクターについて技A、技B、および固有能力を選択。固有能力はSPをリソースとして消費。技単体はMP等を消費）
3. 3の倍数ターン開始時：「突発イベント（ダメージを伴わない全域ステータス低下や属性ダメージの増減など）」の発生宣言。新しいイベント効果が適用され、次の3ターン後まで継続。
4. 行動フェーズ：全キャラクターのコマンド（技A＋技B＋固有能力）が順次発動。行動終了時に各キャラクターのSPが一定量回復。
5. ターン終了時：直近3〜5行の最新ログのみが1行まとめ形式で更新され、次のターンへ。
