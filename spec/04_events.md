# 4. 突発的イベント仕様

バトルの単調化を防ぐため、一定ターンごとに戦況が変化する「突発イベント」が発生するシステムです。

## 4.1 イベント発生トリガーとルール
- **発生周期**：**3ターンごとの固定周期**。（例：3ターン目、6ターン目、9ターン目...）
- **発生タイミング**：対象ターンの開始時にイベントが宣言され、そのターンの戦闘全体に影響を与えます。
- **効果の持続期間**：**次のイベントが発生するまで持続します（3ターン継続）**。新しいイベントが発生した際に、既存のイベント効果は上書きされます。
- **影響対象の範囲**：基本的に「**敵味方全員（フィールド全体）**」が対象となり、公平または双方向的に戦況へ影響を及ぼします。

---

## 4.2 イベント効果のバリエーション
発生する突発イベントは、直接受けるダメージを伴わず、ステータスの増減や特定属性の強化・弱体化を通じてプレイヤーの戦術の切り替えを促す支援・妨害効果です。

### 突発イベント一覧（ランダムで1つが選択・発生）
1. **「防御崩壊」**
   - **効果**：敵・味方すべてのキャラクターの「防御力」が低下する。
2. **「火の昂り（属性活性）」**
   - **効果**：フィールドの火属性ダメージが1.5倍に増加する。
3. **「水の昂り（属性活性）」**
   - **効果**：フィールドの水属性ダメージが1.5倍に増加する。
4. **「風の昂り（属性活性）」**
   - **効果**：フィールドの風属性ダメージが1.5倍に増加する。
5. **「火の静寂（属性減退）」**
   - **効果**：フィールドの火属性ダメージが減少（半減など）する。
6. **「水の静寂（属性減退）」**
   - **効果**：フィールドの水属性ダメージが減少（半減など）する。
7. **「風の静寂（属性減退）」**
   - **効果**：フィールドの風属性ダメージが減少（半減など）する。
8. **「力、集いし時」**
   - **効果**：敵味方全員の攻撃力が一時的に大幅に上昇する。

*※ 直接ペナルティダメージを蓄積するようなイベント、増援系イベント、直接ダメージイベントは一切含みません。*
